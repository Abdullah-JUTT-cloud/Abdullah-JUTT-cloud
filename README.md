## 👨‍💻 About Me

### Hey, I'm Muhammad Abdullah 👋

_⚡ Full-Stack & Systems Engineer · 🎓 BS Software Engineering @ UCP_

<br/>

I don't just write code—I **orchestrate systems** ⚡. While others see databases, APIs, and frontend components, I see **symphonies of data** flowing through high-throughput distributed architectures 🎼.

* 🏥 **Lead Engineer @ MedAlerto:** Architecting real-time telemetry pipelines where medical AI meets low-latency telemetry streams. Think **Kafka streams** pulsing like heartbeats 💓, **microservices** communicating like neurons 🧠, and **predictive models** that save critical seconds.
* 🚀 **Backend AI Engineering:** Scaling asynchronous pipelines, microservices, and high-concurrency event loops.
* 💬 **Real-Time Systems:** Built **Chatify**, a horizontally scalable messaging hub using **Socket.IO** and **Redis Pub/Sub** for zero-lag communication.
* 🛠️ **The Craft:** Transforming **Java/Spring Boot**, **Node.js**, **Python**, and **React** into resilient solutions that don't just work—they **sing** 🔥.

When not debugging production or tuning SQL indices, you'll find me teaching machines to play chess ♟️, dissecting complex system designs 🧩, or building engines that move faster than your morning coffee kicks in ☕.

📍 **Lahore, Pakistan** · 🌍 **Building high-performance software for the world**
